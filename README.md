## 📌 Overview

**Chukakoy Car Rental System** is a web-based academic project developed to streamline and modernize day-to-day car rental operations.  
The platform improves both customer and administrator workflows by combining booking, vehicle management, and payment processing into one centralized system.

Customers can conveniently browse available vehicles, choose rental schedules, and complete reservations online.  
Administrators can manage car listings, monitor reservations, track payment records, and maintain organized rental data for better operational control.

The system also integrates **PayMongo** for secure online transactions and is deployed through **Railway** for cloud-based accessibility.  
Overall, this project provides a practical, user-friendly, and efficient solution for digital car rental service management.

---

## ✨ Key Features

- 🚘 Vehicle listing and availability management  
- 📅 Online booking and reservation scheduling  
- 💳 Secure payment integration via PayMongo  
- 👤 User account and authentication module  
- 🛠️ Admin tools for booking and fleet management  
- ☁️ Cloud deployment through Railway  

---

## 🧰 Tech Stack

- **Backend:** Python, Flask  
- **Frontend:** HTML, CSS, JavaScript  
- **Database:** PostgreSQL  
- **Payment Gateway:** PayMongo  
- **Deployment:** Railway
